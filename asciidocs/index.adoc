= Project Proposal: Vocabulary Trainer
s-elgitHTL

== 1. Überblick über die Aufgabenstellung
Das Projekt hat das Ziel, ein einfaches Programm zu entwickeln, das SchülerInnen Fremdwörter abfragt und speichert, welche Antworten falsch waren.  
Falsch beantwortete Wörter werden dann so lange wiederholt, bis der Lernende sie vollständig beherrscht.  

== 2. Erwarteter Nutzen
- Ständiges Wiederholen von Wörtern, besonders von falsch beantworteten.  
- Lernende erhalten eine klare Übersicht, welche Wörter sie bereits kennen und welche noch nicht.  
- Lernende können ihren aktuellen Lernstand sehen, also wie gut sie die Sprache bzw. die Vokabeln beherrschen.  
- Je nach ihrem Level werden den Lernenden leichtere oder schwierigere Wörter angezeigt.

== 3. Konsequenzen bei Nichtdurchführung
- Lernende müssten weiterhin Papierlisten oder eigene Notizen verwenden. Dabei würden sie Wörter wiederholen, die sie schon kennen, und die schwierigen auslassen, die sie noch nicht beherrschen.  
- Weder SchülerInnen noch Lehrkräfte würden klare Informationen über den Lernfortschritt erhalten.  
- Durch den höheren Aufwand und das fehlende Feedback würden weniger SchülerInnen das gewünschte Sprachniveau erreichen.

== 4. Personelle und finanzielle Rahmenbedingungen
- Team: 3–4 Programmierer 
- Zeitplan: etwa 2 Monate von Beginn bis Fertigstellung (geschätzt)  
- Finanzen: Es werden kostenlose Open-Source-Bibliotheken verwendet, daher entstehen keine zusätzlichen Kosten.
